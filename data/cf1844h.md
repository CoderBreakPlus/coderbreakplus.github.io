只考虑链，成型的环已经没用了。

考虑 $f(x, y, z)$ 表示 $x$ 个 $1$ 元环，$y$ 个 $2$ 元环，$z$ 个 $3$ 元环的方案数。我们发现 $z$ 是很没用的，$z$ 带来的贡献是 $\frac{(x+y+z)!}{(x+y)!}$。我们下面只考虑 $f(x, y)$，容易有如下转移：

- $f(x, y) = (y - 1) \times f(x + 1, y - 2) + x \times (x + y - 1) \times f(x - 1, y - 1)$；
- $f(x, y) = (x - 1) \times f(x - 2, y + 1) + y \times (x + y - 1) \times f(x - 1, y - 1)$。

也就是 $(f(x, y), f(x + 1, y - 2), f(x - 1, y - 1))$ 与 $(f(x, y), f(x - 2, y + 1), f(x - 1, y - 1))$ 两个三元组当中都有知二推三。画个方格大概是这样子：

其中 A, B 知二推三。这让我们想到去维护 $f(x, y), f(x + 1, y + 1)$ 的值。考虑转移：

![](https://cdn.luogu.com.cn/upload/image_hosting/9ih75xlu.png)

如果我们知道两个 $\surd$ 的那么套用 A 可以得到 $1$ 位置的值，套用 B 可以知道 $2$ 位置的值。也就是 $(x, y) \to (x - 1, y + 2)$ 是可以的。同理 $(x, y) \to (x + 2, y - 1)$ 也是可以的。

我们从后往前扫，发现每个 $x, y$，下一次询问只有如下可能：

- $(x, y)$ 此时不变；
- $(x - 1, y + 2)$ 或 $(x + 2, y - 1)$ 调用一次。
- $(x + 1, y + 1)$ 调用 $(x, y) \leftarrow (x + 2, y - 1), (x, y) \leftarrow (x - 1, y + 2)$ 即可。

至此我们完成了本题。挺神奇的。
