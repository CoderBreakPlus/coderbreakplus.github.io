前置：$F_{2n} = \dfrac{\alpha^n - \beta^n}{\sqrt{5}}$，其中 $\alpha = \dfrac{3 + \sqrt{5}}{2}, \beta = \dfrac{3 - \sqrt{5}}{2}$。

考虑树形 DP。合并儿子的时候我们希望用 EGF 维护，但加入根节点的时候我们又希望用 OGF 维护，这是矛盾的。

还是维护 EGF。令 $G_u = \sum_{i \ge 0} g_{u,i}\frac{x^i}{i!}$，其中 $g_{u,i}$ 表示以 $u$ 为根的子树在 $m=i$ 时的答案。

合并儿子就是把所有儿子乘起来。令 $H_u = \prod _{v \in \text{son}(u)} G_v$，我们希望从 $H_u$ 得到 $G_u$。以下把 $u$ 省略。

有 $g_i = \sum_{j \ge 1} F_{2j}h_{i-j}$。考虑将 $\alpha, \beta$ 的贡献拆开算。其实问题等价于算下面这个 $g$：

$$g_i = \sum_{j \ge 1} \alpha^jh_{i-j}$$

关于这个能列出方程（注意是 EGF，求导就是偏移）：

$$G' = \alpha (G + H)$$

---

接下来我们进行一个对 $G$ 和 $H$ 的形式的猜想。我们认为一定能写成若干个 $P_k \text{e}^{kx}$ 之和，其中 $P_k$ 是关于 $x$ 的多项式。也就是 $H = \sum_k P_k \text{e}^{kx}$。

考虑对 $H$ 的某一项 $P \text{e}^{kx}$ 求出对应的 $G$。猜测 $G = Q \text{e}^{kx} + C \text{e}^{\alpha x}$，其中 $Q$ 是多项式，$C$ 是常量。带入 $G' = \alpha (G+H)$ 得到：

$$ (Q' + Qk)\text{e}^{kx} + C \alpha \text{e}^{\alpha x} = \alpha (Q + P) \text{e}^{kx} + C \alpha \text{e}^{\alpha x} $$

化简得到：

$$ Q' + Q(k-\alpha) = \alpha P$$

+ 若 $k = \alpha$ 已经可以用 $P$ 还原 $Q$，其中 $Q$ 的常数项应当是 $0$，$C$ 也是 $0$。
+ 若 $k\neq\alpha$，则 $\deg Q=\deg P$。令 $d=\deg P$，由于 $q_{d+1}=0$，可以通过比较系数从高到低依次求出 $Q$ 的所有系数，最后根据 $G(0)=0$ 得到 $C=-Q(0)$。

这样 $H = P \text{e}^{kx} $ 我们就已经会算了，那对 $H$ 的每一项都这样算出来，利用线性性全部加起来就能得到 $G$，而且依然是 $ \sum_k P_k \text{e}^{kx}$ 的形式。

通过简单分析可以得出 $k$ 一定形如 $k = i \alpha + j \beta$，利用 $(i,j)$ 这样的数对来表达 $k$ 并维护对应的多项式 $P_k$。

又因为可以得到 $i,j$ 非负且 $i+j$ 不超过子树大小，且 $P_k$ 的项数也不超过子树大小，用树上背包的复杂度分析，暴力维护之即为 $\mathcal{O}(n^6)$ 严重不满，可以通过。
