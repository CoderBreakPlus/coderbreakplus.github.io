# AT_aalc001_x 不揃いさ

## 题目描述

给定两个长度为 $N$ 的非负整数序列 $A=(A_1, A_2, \ldots, A_N)$ 和 $g=(g_1, g_2, \ldots, g_N)$，以及一个长度为 $N-1$ 的整数序列 $d=(d_1, d_2, \ldots, d_{N-1})$。注意 $g_j$ 满足 $1 \leq g_j \leq 2$。

通过序列 $g,d$，我们对长度为 $N$ 的整数序列 $B=(B_1, B_2, \ldots, B_N)$ 定义 $f(B)$ 如下。

你可以自由选择一个长度为 $N$ 的整数序列 $C=(C_1, C_2, \ldots, C_N)$。定义 $B$ 和 $C$ 之间的代价为

$$
\sum_{j=1}^{N} g_j |B_j-C_j| + \sum_{j=1}^{N-1} d_j |C_j-C_{j+1}|
$$

其中 $|x|$ 表示 $x$ 的绝对值。

于是，$f(B)$ 就是所有可能的整数序列 $C$ 所能得到的最小代价。

请依次处理 $Q$ 个询问。

在第 $k$ 个询问中，给定整数 $i_k, x_k$，将 $A_{i_k}$ 变为 $x_k$，并计算 $f(A)$。

## 输入格式

从标准输入读入数据，格式如下：

> $N\ Q\ A_1\ A_2\ \ldots\ A_N\ g_1\ g_2\ \ldots\ g_N\ d_1\ d_2\ \ldots\ d_{N-1}\ i_1\ x_1\ i_2\ x_2\ \vdots\ i_Q\ x_Q$

## 输出格式

输出 $Q$ 行。第 $k$ 行输出第 $k$ 次询问后得到的 $f(A)$。

## 说明/提示

### 样例解释 1

在第 1 次询问后，$A=(1,3,2)$。例如选择 $C=(2,2,2)$ 时，代价为 $3$。无法取得比 $3$ 更小的代价，因此 $f(A)=3$。

### 样例解释 2

当 $A$ 所有元素都相等时，选择 $C=A$ 代价为 $0$。

- $1 \leq Q \leq 2 \times 10^5$
- $0 \leq A_j \leq 10^9$
- $1 \leq g_j \leq 2$
- $1 \leq d_j \leq 10^9$
- $1 \leq i_k \leq N$
- $0 \leq x_k \leq 10^9$
- 输入中的所有数值均为整数。
