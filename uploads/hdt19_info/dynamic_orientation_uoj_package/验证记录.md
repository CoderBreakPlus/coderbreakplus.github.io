# 验证记录

- 全部 80 个输入通过独立验证器，按对应子任务检查 n/q 上界、端点大小关系、加删边合法性、query 时偶度、追问紧接 query 且最多十次、行数及答案文件。
- 共 5,020,200 次操作，1,270,185 次哈希查询，650 次追问。
- 新 FHQ 标程与新本地 implementer 联编，80/80 文件输出 AC。
- 本轮最慢文件 test61，墙钟 1.3042 秒。测试在共享执行环境完成，不代表其他评测机上的用时保证。
- 开启 AddressSanitizer 和 UndefinedBehaviorSanitizer，检查了 272,768 个状态：包括六点简单图的全部 32,768 个状态，以及八个种子的随机加删边。检查所有状态的边集合、哈希和度数平衡不变量。当前环境不支持 LeakSanitizer，因此该轮禁用了泄漏检测。
- 慢速参考解通过前 40 个数据。它在 test61 上达到 15 秒超时；这只是包内 brute.cpp 的本次实测，不等价于对所有暴力或所有机器的超时保证。
- 评测库负例：哈希越界、空的非法方案、重复编号、尚未存在的编号、已删除编号、哈希不一致、入出度不平衡，全部拒绝；合法方案通过。
- 验证器拒绝奇度查询、重复加边、删除不存在的边、追问位置错误、u≥v、超过十次追问及整数溢出输入。
- 线上 token 输出协议及公开附件不含 token 的检查通过。
- 未在实际 UOJ 服务器部署试交。
