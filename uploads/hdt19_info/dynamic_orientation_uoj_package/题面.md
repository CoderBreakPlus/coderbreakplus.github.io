### 题目描述

有一个无向简单图 $G$，初始有 $n$ 个点，没有边。顶点编号为 $1$ 至 $n$。

有 $q$ 次操作，分为以下四种：

- 添加连接 $u,v$ 的无向边，编号为 $i$。保证这条边此前不存在。
- 删除连接 $u,v$ 的无向边。保证这条边此前存在。
- 查询当前任意一种合法定向方案的哈希。合法定向要求每个点的入度等于出度，保证查询时所有点的无向度数均为偶数。
- 在上一次查询后，追问与该哈希对应的具体定向方案。

图可以不连通，可以包含孤立点，也可以没有边。每条当前存在的边都必须选择且仅选择一个方向。

为实现在线处理，本题为**函数式交互题**。

### 交互方式

请在代码开头加入：

```cpp
#include "path.h"
```

你需要实现以下五个函数，不要实现 `main`，也不要自行读取标准输入或向标准输出写入内容。

```cpp
void init(int n,int q);
```

该函数仅在程序开始时调用一次。操作总数 $q$ 不包含本次初始化。

```cpp
void add(int u,int v,int i);
```

添加连接 $u,v$ 的边，保证 $1\le u<v\le n$。第一次添加的边编号为 $1$，以后每次添加的编号恰好比上一次添加的编号大 $1$。

**编号是所有添加操作的累计编号，不是操作序号，也不是当前的边数。已删除的编号不会再次使用。同一对端点的边删除后重新添加，会获得新的编号。**

```cpp
void del(int u,int v);
```

删除连接 $u,v$ 的当前边，保证 $1\le u<v\le n$。

```cpp
int query();
```

选择一种使每个点入度等于出度的定向方案。对于当前存在的、编号为 $i$ 的边 $(u,v)$，其中 $u<v$：

- 若方向为 $u\to v$，则 $i\in S$。
- 若方向为 $v\to u$，则 $i\notin S$。

返回的哈希应为：

$$
\left(\sum_{i\in S}2^i\right)\bmod 998244353.
$$

返回值必须在 $[0,998244353)$ 内。没有边时，$S$ 为空，哈希为 $0$。

```cpp
std::vector<int> query_path();
```

返回上一次 `query()` 所选定向方案的集合 $S$，向量中元素的顺序任意，但不得重复，也不得包含已经删除或尚未添加的边的编号。

该函数每个测试文件最多调用 $10$ 次，且调用前的上一个接口调用一定是 `query()`。评测库将检查定向合法性，并通过返回集合的哈希检查上一次 `query()` 的返回值。

保留接口名称 `query_path`；它返回的是**边编号集合**，不是顶点序列。

### 限制与约定

时间限制：每个测试点 $15$ 秒。空间限制：$1024$ MB。

| 子任务 | 分值 | $n,q$ 上限 |
| --- | --- | --- |
| 1 | 25 | 10 |
| 2 | 25 | 1000 |
| 3 | 25 | 50000 |
| 4 | 25 | 200000 |

所有数据满足 $1\le n,q$。每个子任务含 $20$ 个测试点，必须全部通过才能获得该子任务分数。

### 本地测试

附件包含 `path.h`、`implementer.cpp`、代码模板以及样例。请使用 C++17 编译：

```sh
g++ -std=c++17 -O2 implementer.cpp solution.cpp -o solution
./solution < sample.in
```

测试文件第一行为 `n q`，随后恰有 $q$ 行操作：

- `1 u v`：添加边，评测库自动按添加次数生成编号 $i$，调用 `add(u,v,i)`。
- `2 u v`：调用 `del(u,v)`。
- `3`：调用 `query()`。
- `4`：调用 `query_path()`。

**文件中的添加操作仍只有三个整数，不另行写入编号。**这一文件格式供评测库使用，选手程序只通过函数参数接收操作。

### 样例输入

```text
4 10
3
1 1 2
1 2 3
1 1 3
3
4
2 1 3
1 1 3
3
4
```

### 本地评测库输出

```text
AC
```

### 样例说明

第一次查询时没有边，应返回 $0$。

第二次查询时，可以将三条边定向为 $1\to2$、$2\to3$、$3\to1$。此时 $S=\{1,2\}$，哈希为 $2^1+2^2=6$。

重新添加的 $(1,3)$ 的编号为 $4$。第三次查询时，可以选择反向的环，令 $S=\{4\}$，返回 $16$。

顶点 $4$ 始终为孤立点，其入度和出度均为 $0$，符合要求。
