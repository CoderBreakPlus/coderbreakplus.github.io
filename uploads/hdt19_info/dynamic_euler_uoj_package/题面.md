### 题目描述

有一个无向简单图 $G$，初始有 $n$ 个点，没有边。点的编号为 $1$ 至 $n$。

有 $q$ 次操作，分为以下四种：

- 添加一条连接 $u,v$ 的无向边，保证这条边此前不存在。
- 删除连接 $u,v$ 的无向边，保证这条边此前存在。
- 查询当前一条欧拉回路的哈希值。保证此时图连通、没有孤立点，且所有点的度数均为偶数。
- 在上一次查询后追问对应的具体欧拉回路。

欧拉回路必须恰好经过当前图中的每条边一次。你可以选择任意一条欧拉回路，但返回的具体回路必须与上一次查询的哈希一致。

为实现在线处理，本题为**函数式交互题**。

### 实现接口

请在代码开头加入：

```cpp
#include "path.h"
```

你需要实现以下五个函数，不要实现 `main`，也不要自行读取标准输入或向标准输出写入内容。

```cpp
void init(int n, int q);
```

该函数只在程序开始时调用一次，告知点数和操作总数。操作总数不包含这次初始化。

```cpp
void add(int u, int v);
void del(int u, int v);
```

分别对应添加和删除边，保证 $1\le u,v\le n$ 且 $u\ne v$。

```cpp
int query();
```

设当前有 $m$ 条边，你选择的欧拉回路的顶点序列为 $s_0,s_1,\ldots,s_m$。要求 $s_0=s_m$，并且相邻顶点对应的无向边恰好遍历图中所有边一次。

返回：

$$
\left(\sum_{i=0}^{m}s_i 100^i\right)\bmod 998244353.
$$

返回值必须在 $[0,998244353)$ 内。起点可以任意选择，哈希包含末尾重复出现的起点。

```cpp
std::vector<int> query_path();
```

返回上一次 `query()` 对应的顶点序列，共 $m+1$ 个元素。

该函数每个测试文件最多被调用 $10$ 次，且调用前的上一个接口调用一定是 `query()`。评测库检查欧拉回路是否合法，并检查其哈希是否与上一次 `query()` 的返回值相等。

### 限制与评分

时间限制：每个测试点 $15$ 秒。空间限制：$1024$ MB。

| 子任务 | 分值 | $n,q$ 上限 |
| --- | --- | --- |
| 1 | 25 | 10 |
| 2 | 25 | 1000 |
| 3 | 25 | 50000 |
| 4 | 25 | 200000 |

所有数据满足 $1\le n,q$。每个子任务含 $20$ 个测试点，必须全部通过才可获得该子任务分数。

### 本地测试格式

附件提供 `path.h`、`implementer.cpp`、代码模板及样例。请使用 C++17 编译，例如：

```sh
g++ -std=c++17 -O2 implementer.cpp solution.cpp -o solution
./solution < sample.in
```

本地测试文件第一行为 `n q`，随后恰有 $q$ 行：

- `1 u v`：调用 `add(u,v)`。
- `2 u v`：调用 `del(u,v)`。
- `3`：调用 `query()`。
- `4`：调用 `query_path()`。

此输入格式仅供评测库使用，选手程序通过函数参数接收操作。

### 样例输入

```text
3 9
1 1 2
1 2 3
1 1 3
3
4
2 1 3
1 1 3
3
4
```

### 本地评测库输出

```text
AC
```

### 样例说明

第一次查询时，可以选择回路 $1,2,3,1$，其哈希为 $1030201$。

第二次查询时图恢复为同一个三角形，可以选择相同回路，也可以选择其他合法回路。每次追问返回的回路必须与紧接在它之前的查询返回值匹配。
